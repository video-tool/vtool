# Swiss-Ski Video-Lab

Video-Analyse für Coaches: Ski-Videos lokal öffnen, verlangsamen, Bild für Bild durchgehen und zwei Läufe nebeneinander oder überlagert vergleichen.

**Link:** https://video-tool.github.io/vtool/

- Videos werden nur im Browser geöffnet und **nie hochgeladen** (Object-URL, keine Cloud).
- Zwei Modi: **Einzelvideo** und **Vergleich** (A/B, synchronisierbar).
- Zeitleiste mit Vorschaubildern: ziehen, Mausrad oder Pfeiltasten = 1 Bild; reinzoomen bis jedes Bild ein eigenes Feld hat.
- fps wird automatisch gemessen.
- Eine einzige Datei: `index.html`, keine Abhängigkeiten.

Tastenkürzel: in der App unter dem Tastatur-Symbol oder mit `?`.
